Back2Live

Můj první větší frontend projekt vytvořený v HTML, CSS a JavaScriptu.

Back2Live je edukativní web zaměřený na témata spánku, regenerace, výživy a zdravých návyků. Cílem projektu bylo vytvořit moderní responzivní web s vlastní strukturou a obsahem.

Co projekt obsahuje

* responzivní design
* vícestránkovou navigaci
* vlastní články a obsah
* produktovou sekci
* kontaktní stránku
* základní JavaScript
* organizaci projektu do více složek

Technologie

* HTML
* CSS
* JavaScript
* Git
* GitHub Pages

* vytvářet responzivní layouty

* propojovat jednotlivé stránky
* pracovat s GitHub Pages
