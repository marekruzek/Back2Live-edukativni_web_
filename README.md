Back2Live

Můj první větší frontend projekt vytvořený v HTML, CSS a JavaScriptu.

Responzivní edukativní blog zaměřený na zdravý režim, spánek a každodenní návyky. Design je postavený na čisté typografii, kartách, ikonách a přehledné obsahové struktuře bez závislosti na fotobankových obrázcích.

Co projekt obsahuje

* responzivní design
* vícestránkovou navigaci
* vlastní články a obsah
* produktovou sekci
* kontaktní stránku
* základní JavaScript
* organizaci projektu do více složek

Technologie

* HTML
* CSS
* JavaScript
* Git
* GitHub Pages

Co jsem se na projektu naučil

* vytvářet responzivní layouty
* organizovat soubory a složky projektu
* propojovat jednotlivé stránky
* pracovat s GitHub Pages
* připravit projekt jako součást svého portfolia
